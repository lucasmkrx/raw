# Brand guidelines

Always use the complete logo: RAW lettering, TECHNOLOGIES tagline, and claws together. Keep the original proportions and arrangement, including in avatars and favicons.

## Colors and versions

| Version | Colors | Background |
| --- | --- | --- |
| Color | White lettering, green claws (`#40DA66`) | Dark |
| White | All white (`#FFFFFF`) | Dark |
| Black | All black (`#000000`) | Light |

The color version preserves the source colors. Green is RGB 64, 218, 102. These are screen colors; print conversions should be proofed by the printer.

Use SVG when supported, or the 2048px-wide transparent PNG when raster artwork is required. The square 1024px profile image has an opaque black background and uses the full color logo at 76% of canvas width, centered to fit a circular crop.

## Placement

Keep clear space around the logo. A working rule for new layouts is at least one quarter of the logo canvas height. Check readability at the final display size; the TECHNOLOGIES tagline becomes very small in browser tabs. Increase the display size where possible while keeping the logo complete.

Do not stretch, rotate, crop, rearrange, or separate the logo components. Use the provided colors without added outlines, shadows, or effects. The lettering is outlined in the source, so no font installation is needed.
